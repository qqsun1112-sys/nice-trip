# WELCOME50 第一階段對外文字與規則（待上線審核）
2026-10-20 使用者改定：**每位符合資格付費參加者各折 NT$50**，同筆訂單輸入一次 WELCOME50；不再採每筆訂單總折 NT$50。

## LINE 優惠券說明（建議文字，尚未寫入 LINE）
美遊記・加入好友見面禮
每位付費參加者現折 NT$50！
一人折 NT$50、兩人折 NT$100、三人折 NT$150。
限美遊記指定付費城市故事行旅；依同筆訂單符合資格之付費人數計算。每筆訂單限使用優惠碼 WELCOME50 一次，不與其他優惠券併用。免費及非指定活動不適用。有效期限至 2026/12/31 23:59（台灣時間）。
報名時於美遊記官網輸入優惠碼，以系統確認後之金額為準。

## 官網報名頁（建議文字，尚未部署）
LINE 好友見面禮｜每位付費參加者折 NT$50
於指定付費城市故事行旅報名時輸入 WELCOME50，系統依符合資格之付費參加人數計算：1人折50元、2人折100元、3人折150元。每筆訂單輸入一次，不與其他優惠券併用。優惠至 2026/12/31 23:59（台灣時間）。實際折抵以確認訂單明細為準。

## 風險與限制
- WELCOME50 為共用碼，官網不驗證 LINE 領券狀態；LINE「使用一次」與官網折抵不是同步核銷。
- 「每筆訂單輸入一次」不等於「每人只能享一次優惠」。若要跨訂單限制須另訂驗證規則。
- 現有離線試算假設單一票價、全數參加者付費且符合資格；混合票種及指定活動的後端邏輯仍需完成。
- 不可把此草稿視為已發佈；不得在未驗證伺服器端金額計算及完整報名流程前啟用。
