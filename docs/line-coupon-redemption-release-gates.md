## 目前事實
LINE OA 優惠券「美遊記・好友同行禮」已儲存為草稿；好友介紹領取；介紹期間 2026-10-20 00:00 至 2026-12-31 23:59（台灣時間）；領取後 30 天內有效；面額 NT$50。LINE OA 的「已領取」與「已使用」狀態不會自動同步到 nicetrip.tw 的 Supabase registrations。

## 強制的正常報名保護
1. 沒選優惠的報名者沿用既有票價、報名、匯款回報、取消、Email 與後台流程。不得強迫登入 LINE 或輸入優惠券。
2. 選了優惠但無法核對時，不可靜默恢復原價並送單；顯示原因及原價，取得使用者明確同意後才走原價報名。
3. 每人每場最多使用一張、折 NT$50；限指定自辦「城市故事行旅」付費活動；一般票、早鳥票等可併用；免費活動及未指定服務不可用。
4. 前端優惠券號碼、截圖、LINE 顯示畫面不構成可信核銷證據；由服務端確認身份、活動、使用紀錄、有效期間及是否已用過。
5. LINE 優惠券若無可用的官方核銷／查詢 API 或可稽核的人工作業，禁止標示「已完成自動核銷」。必須先定義由誰核對、何時標記 LINE 已使用、如何避免跨系統重複核銷。

## 原子交易的最低條件
在隔離 Supabase 測試專案中，於同一交易中：
- 驗證活動可報名、票價取自資料庫，鎖定活動及可用名額；不可相信瀏覽器傳來的單價或折扣。
- 對每位參加者鎖定已驗證、未核銷、屬於本活動且尚在有效期內的資格；資料庫 unique 約束防止重複核銷。
- 建立 registrations 與折抵快照：原始金額、優惠活動 ID、每人折抵、總折抵、實付金額；建立獨立 redemption 稽核紀錄。
- 任一步失敗整筆 rollback，不得扣優惠但沒報名，或報名成功卻沒有扣資格。
- 保留原 create_registration_atomic 的容量鎖定及既有授權邊界；未經驗證不可擴大 RPC execute 權限。
- 對重送請求使用 idempotency key；取消與退款須另定義優惠券是否恢復資格，不得自動假設 LINE 同步復原。

## 需驗證的整合情境
- 無優惠：單人、多人、額滿、取消、付款、Email、後台帳務完全不變。
- 優惠：一人成功、多人逐人核對、只有部分人有券、重複提交、重複身份、已核銷、過期、跨活動、非自辦或免費活動。
- 時間：活動介紹期間與每張券領取後 30 天是兩個獨立期限；以 Asia/Taipei 判定。
- 故障：LINE 驗證逾時、資料庫交易失敗、網路重送、Email 發送失敗。
- 觀察：正常報名成功率、價格一致性、重複核銷次數、異常回退流程。
