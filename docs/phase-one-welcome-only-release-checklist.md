## 實作前尚需確認的細節
- 目前無法僅靠共用碼證明「每人每場限一次」。若強制此限制，需明確的個人辨識、隱私規則、重複報名處理及伺服器端原子限制；不能假裝共用碼已做到。
- 單筆多人報名：建議先採**每筆報名最多折抵 NT$50 一次**，避免一個共用碼自動替多名同行者各折50；如要每人折50，須另行核准規則。
- LINE 端「使用一次」與官網使用紀錄互不相通，LINE 端點選「使用」並不自動核銷網站折扣。
- 需定義指定活動的後台開關（預設關閉）、取消報名後折扣使用紀錄是否恢復、既有票價與早鳥價是否可搭配。
- 如系統故障，**不能默默按原價提交**；需請報名者明確選擇原價或稍後再試。
